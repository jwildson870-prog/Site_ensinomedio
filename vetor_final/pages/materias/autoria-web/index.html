02 · Descobertas
Curiosidades em movimento
Seis pequenas descobertas para ampliar o contexto sem tirar o foco do conteúdo.
WEB · 01

A Web nasceu no CERN

Tim Berners-Lee propôs a World Wide Web em 1989 enquanto trabalhava no CERN.

HTML · 02

HTML dá estrutura

HTML descreve a estrutura e o significado do conteúdo de uma página; CSS cuida da apresentação.

CSS · 03

CSS separa estilo

CSS foi criado para controlar a apresentação visual de documentos estruturados sem misturar estilo ao conteúdo.

JAVASCRIPT · 04

JavaScript ganhou vida rápido

Brendan Eich criou a primeira implementação do JavaScript em 1995 durante o desenvolvimento do navegador Netscape.

ACESSIBILIDADE · 05

A Web é acessível

Semântica, contraste, foco, textos alternativos e navegação por teclado ajudam a tornar interfaces mais inclusivas.

RESPONSIVIDADE · 06

Responsividade é adaptação

Um layout responsivo reorganiza conteúdo e controles para diferentes tamanhos e formas de tela.
